# QA Automation Playground

Project created for practicing Java API test automation and core Java concepts.

## Tech stack

- Java 11
- Maven
- JUnit 5
- AssertJ
- WireMock
- Rest Assured
- Jackson

## What is covered

- GET requests
- POST requests
- HTTP status validation
- JSON body assertions
- Path parameters
- Query parameters
- Headers
- WireMock stubbing
- Request verification
- JSON deserialization

## How to run tests

From IntelliJ IDEA:

1. Open the Maven project.
2. Reload Maven dependencies.
3. Run test classes from `src/test/java`.

From terminal:

```bash
mvn test
